# عدسة (Adasa) - مدونة التصوير الفوتوغرافي 📸

مشروع تطبيقي متكامل لمدونة تصوير فوتوغرافي باستخدام **React** و **React Router** و **Tailwind CSS**.

---

## 🌟 المميزات والمطلوبات المنجزة (Assignment 14)

### 1️⃣ الصفحة الرئيسية (Home Page - `/`)
- **Hero Section**: عنوان رئيسي جذاب مع إحصائيات المنصة (28+ مقال، 5 تصنيفات، 100% محتوى عربي).
- **التدوينات المميزة**: عرض المقالات التي تم تمييزها (`featured: true`) ببطاقات عريضة غنية بالمعلومات.
- **استكشف التصنيفات**: بطاقات تفاعلية لكل تصنيف (إضاءة، بورتريه، مناظر طبيعية، تقنيات، معدات) مع عدد المقالات لكل تصنيف ورابط مباشر للفلترة.
- **أحدث التدوينات**: استعراض أحدث 6 مقالات أضيفت للمدونة مع زر الانتقال للمدونة الكاملة.
- **اقتباس وبانر النشرة البريدية**: تصميم عصري بالخط العربي الجميل (Tajawal).

---

### 2️⃣ صفحة المدونة (Blog Page - `/blog`)
- ✅ **البحث الفوري (Live Search)**: إمكانية البحث في الوقت الفعلي بالعنوان، المقتطف، الكاتب، الوسوم، أو المحتوى الكامل مع زر تفريغ البحث.
- ✅ **فلترة التصنيفات (State Filtration)**: فلترة حقيقية باستخدام React State وعناوين الـ URL (`useSearchParams`) دون استخدام Navs & Tabs التقليدية.
- ✅ **تغيير طريقة العرض (Grid View & List View)**:
  - **عرض شبكي (Grid)**: بطاقات رأسية أنيقة ومحاذية لثلاثة أعمدة.
  - **عرض قائمة (List)**: بطاقات أفقية تفصيلية مع مقتطفات أطول وعرض الوسوم.
- ✅ **الترقيم والتنقل بين الصفحات (Pagination - BONUS 🎁)**:
  - عرض 6 تدوينات في كل صفحة.
  - أزرار أرقام الصفحات مع أزرار (السابق / التالي).
  - إعادة تعيين تلقائي للصفحة الأولى عند تغيير البحث أو التصنيف.
  - صعود سلس لأعلى القائمة عند التنقل بين الصفحات.
- **ترتيب المقالات**: إمكانية الفرز حسب (الأحدث تاريخاً، الأقدم، الأطول قراءة).
- **حالة عدم العثور على نتائج (Empty State)**: واجهة لطيفة مع زر إعادة ضبط الفلاتر.

---

### 3️⃣ صفحة تفاصيل التدوينة (Blog Details Page - `/blog/:id`)
- مسار ديناميكي يعتمد على معرف المقال (`useParams()`).
- مسار التصفح (Breadcrumbs).
- معلومات الكاتب، تاريخ النشر، وقت القراءة، والتصنيف.
- تنسيق ذكي لنصوص الماركداون (عناوين فرعية بأيقونات مميزة، قوائم نقطية، وفقرات متناسقة).
- أزرار المشاركة الاجتماعية (X / تويتر، فيسبوك، نسخ الرابط المباشر).
- استعراض الكاتب ونبذة عنه.
- التنقل بين المقال السابق والتالي.
- مقالات ذات صلة (Related Posts) من نفس التصنيف.

---

### 4️⃣ صفحة الخطأ (404 Not Found Page - `*`)
- صفحة مصممة بروح التصوير الفوتوغرافي عند زيارة أي مسار غير موجود.
- أزرار سريعة للعودة للصفحة الرئيسية أو الانتقال للمدونة.

---

### 🎁 صفحات إضافية مكتملة (Bonus Pages)
- **من نحن (`/about`)**: قصة المنصة، رؤيتها، وقائمة بجميع الكتّاب والمصورين المساهمين.
- **شروط الاستخدام (`/terms`)**: اتفاقية شروط الاستخدام.
- **سياسة الخصوصية (`/privacy`)**: وثيقة سياسة الخصوصية وحماية البيانات.

---

## 🛠️ التقنيات المستخدمة
- **React 19**
- **React Router DOM 7** (BrowserRouter, Routes, Route, NavLink, Link, useParams, useSearchParams)
- **Tailwind CSS 4**
- **Lucide React** (أيقونات فوتوغرافية وعصرية)
- **خط تجوال (Tajawal Google Font)** - اتجاه كامل من اليمين لليسار (`dir="rtl"`).

cd adasa

npm run dev
